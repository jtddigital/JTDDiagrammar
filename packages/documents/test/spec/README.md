# Markdown spec examples (URS-WS-040)

Test data only, used by `../markdown-spec.test.ts`; never shipped.

- `commonmark.json`: every example of the [CommonMark Spec 0.31.2](https://github.com/commonmark/commonmark-spec/blob/0.31.2/spec.txt), by John MacFarlane, CC-BY-SA 4.0.
- `gfm.json`: the extension examples of the [GitHub Flavored Markdown Spec 0.29-gfm](https://github.com/github/cmark-gfm/blob/master/test/spec.txt) (tables, strikethrough, task lists, extended autolinks, disallowed raw HTML) and the footnote examples of [cmark-gfm's extension tests](https://github.com/github/cmark-gfm/blob/master/test/extensions.txt), CC-BY-SA 4.0.

Extracted from the spec texts: each example's Markdown and expected HTML, with `→` turned back into a tab.
